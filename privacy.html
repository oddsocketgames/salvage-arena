Privacy Policy

Salvage Arena, by Odd Socket. Last updated 10 October 2026.

Salvage Arena is a small game made by Odd Socket ("we", "us"). We collect as little as we can. We have no ads, no analytics, no tracking and no accounts with passwords, and we never sell or share your data. This page lists everything the game, the launcher and this website do with information about you.

What stays on your PC

Your saves, settings, run history, screenshots, crash reports and bug reports are kept in %LOCALAPPDATA%\SalvageArena on your computer. The game never uploads them. A crash or bug report is only sent to us if you choose to send it yourself.

Friends leaderboards

From version 0.13 (and in the 3D beta), when you're connected and a run ends, the game sends your score on that run's leaderboard (the daily, the weekly, your robot's Arena board, endless or boss rush) to our server, with the robot you played and the wave you reached. The server keeps only your best score on each board, stored with your random player ID. Only you and your friends can see it, next to your display name; nobody else can. Old daily boards are deleted after 14 days. Runs where tester tools were used are never sent.

The friends list (Salvage Arena server)

If you use the friends list, the game connects to our server and it stores:

  • a random player ID and secret, made by the server (your copy is kept in friends.ini in your save folder),
  • your friend code and the display name you use in the game,
  • your friends list and pending friend requests,
  • the date your player ID was created,
  • your best leaderboard scores, as described above.

While you're connected, the server also keeps in memory whether you're online, in a lobby or in a run, and your game version, so it can show your friends your status. It forgets this when you disconnect. Your friends can see your display name, friend code and status. People who aren't your friends can't.

Like any internet server, ours sees your IP address while you're connected. It uses the address only to send you data and to limit how many connections one address can open. When you play co-op through the server, it passes game traffic between the players in the lobby and keeps nothing of it. The server's log records when a new player ID is made (ID, display name, friend code) and any errors. It does not log IP addresses.

The server runs on Microsoft Azure in the United States.

Co-op by IP address

If you join a game by typing an address, the game connects straight to the host. The host's and players' computers then see each other's IP addresses, as in any direct online game.

Discord status (Rich Presence)

If the Discord desktop app is running, the game tells it what you're doing: the wave and arena, your robot, the threat level, your co-op party size and how long you've played. Discord then shows this on your profile. This goes from the game to the Discord app on your own PC (through a small helper program, SalvagePresence.exe). We don't receive it. What Discord does with it is covered by Discord's Privacy Policy. To turn it off, open Discord's User Settings > Activity Privacy and switch off sharing your detected activities.

The launcher and updates

The launcher asks GitHub for the latest version and downloads the game from GitHub. GitHub sees your IP address for these requests, as described in the GitHub Privacy Statement. We don't get any information from this.

This website

This site is hosted on GitHub Pages. It sets no cookies and loads nothing from other sites. It asks GitHub's API for the current version number. GitHub may log visits as described in its privacy statement.

Keeping and deleting your data

Friends-list data and leaderboard scores are kept until you ask us to delete them, or until the playtest server shuts down. To have your player ID, name, friend code and friends list deleted, contact us with your friend code (shown under CO-OP > FRIENDS). Deleting friends.ini only makes the game start a fresh player ID. It doesn't remove the old one from the server.

Children

Salvage Arena is not made for children under 13, and we don't knowingly collect anything from them. If a child has used the friends list, contact us and we'll delete it.

Changes

If this policy changes, we'll update this page and the date at the top.

Contact

Questions or deletion requests: open an issue at github.com/oddsocketgames/salvage-arena/issues. Don't post anything private there. A friend code is enough.
